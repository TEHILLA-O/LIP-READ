# --- numerical / vision ---
numpy>=1.26

# Pinned deliberately. MediaPipe removed the legacy `mp.solutions` API in
# 0.10.30+; those builds expose only the Tasks API, which needs a separately

# wheel, so setup works offline and matches the detector the Auto-AVSR
# preprocessing was designed around. Moving to a newer MediaPipe means
# rewriting ml/preprocessing/face_detector.py against Tasks.
